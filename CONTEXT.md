# Colección de skills

Skills reutilizables que se distribuyen entre agentes y dispositivos sin mezclar sus identidades.

## Lenguaje

**Módulo**:
Colección con un mantenedor y una identidad compartidos. Una skill propia o adaptada localmente pertenece a `personal`; una importación sin adaptar pertenece al módulo de su autor.
_Evitar_: carpeta temática, autor original como sustituto del mantenedor actual.

**Nombre cualificado**:
Identidad pública de una skill que combina módulo y nombre, por ejemplo `matt-pocock:tdd` o `addyosmani:test-driven-development`.
_Evitar_: nombre global sin procedencia.

**Procedencia**:
Origen de una skill y de sus recursos, conservado incluso cuando una adaptación cambia de módulo.
_Evitar_: asumir que pertenecer a `personal` elimina la atribución de origen.
